# Datasets

* [UCO LinkML schema](uco-linkml-schema.md) - The LinkML schema of the Unified Cyber Ontology (UCO) 1.5.0, `src/uco/schema/uco.yaml` (schema id `https://w3id.org/lmodel/uco`) with sixteen modules, one per UCO namespace and one for the Collections Ontology terms UCO uses: 425 classes, 771 slots, 53 enums and 14 types, all written by a converter. Its `lokf adapt` copy `.lokf/uco.yaml` is the bundle's domain schema.
* [The UCO 1.5.0 copy](uco-copy.md) - UCO's own files at release 1.5.0, 79 files copied into `src/uco/schema/upstream/` under UCO's paths: the seventeen Turtle files of the ontology, UCO's LICENSE, and the passing and failing examples with the SHACL reports on the failing ones. Each is matched to commit `7ebb3957e9e9` by git object hash.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and 425 Java classes), the Python dataclasses and Pydantic models in `src/uco/datamodel/`, `docs/schema/`, and `.lokf/uco.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: 228 valid examples under `tests/data/valid/`, 28 of them from UCO's own examples and 200 minimal ones written from the schema, 17 counter-examples, one per kind of constraint, the check that holds each fault of UCO's failing examples to the validator, and the tests of the watch, the copy and the adapt copy against nine released neighbours.
