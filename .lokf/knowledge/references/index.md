# References

* [The Unified Cyber Ontology (UCO)](unified-cyber-ontology.md) - The Unified Cyber Ontology (UCO), release 1.5.0 of July 24, 2026, at <https://github.com/ucoProject/UCO>: a community ontology for cyber-domain information in OWL and SHACL, in fifteen namespaces, which the schema renders.
* [The Collections Ontology (CO)](collections-ontology.md) - The Collections Ontology (CO) 2.0, <http://purl.org/co/>, whose bag, list and item classes UCO's threads build on. Its files state no licence, so the schema's `uco_co` module renders the terms UCO's files use with descriptions of its own.
