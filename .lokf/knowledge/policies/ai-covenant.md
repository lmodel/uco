# AI covenant

`AI_COVENANT.md` says that whoever submits a contribution is its author, whatever tools helped, and must understand and defend it.[^ai_covenant.md]

Its note for this project names the failure mode it guards against: a class, property or constraint a model produced, presented as what UCO says. So the schema is the converter's output, and a change to the converter cites the part of UCO's files a rule reads. The copy of UCO's files is upstream text, never edited. Every element keeps its UCO IRI, and only what the converter adds lives under `uco_linkml:`. Disclosure is required for a converter rule an AI drafted.
