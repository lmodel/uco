# Policies

* [Security policy](security-policy.md) - How to report a vulnerability (GitHub's private vulnerability reporting), which release receives fixes (the latest), what executes in the repository and what holds each surface, the ruleset on `main`, and the two repository settings that are not yet in force.
* [AI covenant](ai-covenant.md) - The repository's rules for work done with artificial intelligence (AI): you own what you submit, the schema is the converter's output and a rule cites the part of UCO's files it reads, the copy of UCO's files is never edited, and every element keeps UCO's IRI.
* [License and attribution](license-and-attribution.md) - The repository's licences: Apache 2.0 for the schema and the code, the UCO Community's Apache 2.0 for the copy of UCO's files and the descriptions taken from it, Apache 2.0 for the copy of lmodel/collections' module, MIT for the copier template's scaffolding, Apache 2.0 for the KTL templates, and CC BY 4.0 for the knowledge bundle.
